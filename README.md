# Ink Wars: Fold & Fight

Mobile-friendly paper battlefield strategy game built with Phaser 3 and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

GitHub Pages deployment workflow is included but requires manually enabling Pages with **GitHub Actions** as the source. No automatic publication has been configured by this action.

## How to play

Select a unit from the bottom bar, then tap on the left half of the battlefield to deploy. Press **FOLD** to bring opposing units closer. Units attack automatically. Win by eliminating all red units. Survive with at least one blue unit. Campaign levels and survival mode are included.
